# Tagger data

Labeled text for the Bi-LSTM-CRF TASK/DATE tagger.

**Never put real mailbox content here.** No email bodies, snippets or in-app
corrections from real Gmail accounts, including your own. Google's API
Limited Use rules forbid training generalized models on Gmail data. Everything
here is synthetic or written by the team.

| Folder | What goes in it | Used for |
|---|---|---|
| `synthetic/` | Generated by `python -m training.generate_synthetic` (not committed) | Training and the dev set |
| `team/` | Example emails the team writes, in markup | Training |
| `corrected/` | Team-written examples the model got wrong, with the labels fixed | Training |
| `test/hand_labeled.md` | About 100 emails you write and label yourself | The fixed test set |
| `test/provisional_claude.md` | About 45 emails written by Claude | Test set only until `hand_labeled.md` has emails |

## Markup format

One email per block. Blocks are separated by a line containing only `---`.
`# lang: en`, `# lang: tl` or `# lang: taglish` sets the block's language (used
for the per-language scores). Other lines starting with `#` are comments.

```
# lang: taglish
Hi team, [TASK]paki-send ang final weekly report[/TASK] [DATE]bukas[/DATE]. Salamat!
---
# lang: en
[TASK]Please review the attached budget[/TASK] before [DATE]Friday at 3 PM[/DATE].
```

Check a file with `python -m training.convert_markup data/test/hand_labeled.md`.

## Labeling rules

**TASK**: the requested action, from the request word to the end of the
request clause.

- Start at the request word: please, kindly, can you, could you, pls,
  make sure to, don't forget to, you need to, paki-/paki, pakisuyong, pa-,
  kailangan mong/ninyong, pwede bang. An order with no request word
  ("Submit the form") starts at the verb.
- Keep everything that is part of the request: the object and its details,
  where it goes, and "whether" clauses.
  `[TASK]please return the signed forms to the adviser[/TASK]`,
  `[TASK]Pakiprint ng 30 copies ng handout[/TASK]`,
  `[TASK]please confirm if the venue can take 80 guests[/TASK]`,
  `[TASK]I-upload niyo na yung video sa drive[/TASK]`.
- Stop before:
  - a date;
  - a deadline word (by, before, until, on, no later than, bago, hanggang);
  - a reason or purpose ("kasi…", "dahil…", "para…", "so we can…", "to avoid…");
  - a condition or time clause ("if you have time", "kung may oras ka",
    "pag-uwi mo");
  - punctuation.
- Leave out particles at the very end (`po`, `naman`, `na`, `ha`); particles in
  the middle stay: `[TASK]paki-send naman ang report[/TASK]`.
- Not a task: "Please find attached…", "Please note…", "Kindly be advised…",
  "Thank you for submitting…", "Na-submit ko na…" (already done), plain news
  ("Your order has shipped", "Attendance is required").

**DATE**: any date or time expression, future or past.

- Include modifiers and times: `next Monday`, `this Friday`, `tomorrow morning`,
  `Friday at 3 PM`, `bukas ng umaga`, `mamayang gabi`, `Nov 20`.
- Include `sa` when it belongs to the date: `sa Biyernes`, `sa susunod na linggo`.
- Leave out deadline words: by, before, on, until, bago, hanggang.
- Past dates are still DATE ("kahapon", "last Friday"). The service decides
  separately whether a date is a deadline.
